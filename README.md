# Vicky Portfolio Website

A responsive and modern portfolio website built with React, Tailwind CSS, JavaScript, and Vite.

## 🚀 Features

* Responsive Design
* Modern UI/UX
* About Me Section
* Skills Showcase
* Projects Gallery
* Contact Information
* Resume Download
* Custom Developer Cursor
* Mobile Friendly

## 🛠️ Tech Stack

* React
* Tailwind CSS
* JavaScript
* Vite
* HTML5
* CSS3

## 📂 Installation

```bash
git clone https://github.com/sathiyaraj16/vicky-portfolio.git
cd vicky-portfolio
npm install
npm run dev
```
